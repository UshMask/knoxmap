# План реализации KnoxMap Eastern Europe

**Цель.** Развить KnoxMap в инструмент воссоздания узнаваемых реальных городов в Project Zomboid. Киров — первый контрольный город. Геометрия улиц, застройка, транспорт, предметы и состояние города должны согласовываться между собой. Восточноевропейский профиль задаёт местные особенности, а инструментарий должен работать и с другими городами.

`codex/eastern-europe-maps` — основная рабочая ветка проекта в форке `UshMask/knoxmap`. Из неё запускается общая проверка. В ней собираются правки рельсов, улиц, транспорта и секций зданий. Статус каждого результата фиксируется в соответствующем ТЗ.

## Как вести работу

- **Первый выпуск — этапы 01–03.** Он проверяет, что улучшение проходит через штатный процесс `Generate → Build → Compile → Install`. Даты и переходы можно реализовать и проверить отдельными изменениями.
- **Дальше — одна возможность за раз.** Внутри этапа сначала доводим один вертикальный срез до экспорта, затем берём следующий. Для каждого результата сохраняем commit, входы, команды, показатели и пути к артефактам. Проект, кэш и данные игры хранятся локально в соответствии с [правилами проекта](../../CONTRIBUTING.md).
- **Уровни проверки.** Офлайн проверяем исходники, планы, тайлы, отчёты, скомпилированные ячейки и пакет. Поведение движка проверяется отдельным прогоном в изолированном сохранении по согласованию. Факт упаковки, работоспособность в игре и доступность в Workshop фиксируются отдельно.
- **Принцип расширения.** Существующий генератор получает данные и правила по мере необходимости. Каждый новый слой имеет конкретного потребителя, пример на Кирове и проверку. Форматы и переключатели вводятся вместе с использующей их функцией.
- **Проверка целого квартала.** Используем один снимок исходных данных и сравниваем тот же маршрут, перекрёсток, двор и дом. По штатному профилю фиксируем видимые изменения покрытия, предметов и помещений. По игровой проверке фиксируем фактическую плотность машин и начальное состояние города. Число настроек, зон спавна и отчётов помогает диагностике. Итог оценивается по тому, что получилось на карте и в игровом мире.
