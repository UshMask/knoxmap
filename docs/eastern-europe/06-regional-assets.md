# ТЗ 06. Региональные ресурсы и зависимости Workshop

Вход — рабочие улица и здания из [04](04-streets-and-vehicles.md) и [05](05-buildings-and-data.md). Результат — два варианта карты контрольного района, один использует штатные ресурсы, другой подключает проверенный набор. Далее — [07. Сценарии города](07-city-scenarios.md).

## 06А. Первый пакет тайлов

1. Взять Fantasiado’s More Street Details как кандидата для первой интеграции. В опциональном профиле назначить одну роль, например разметку автобусной остановки. Сопоставить роль с точным идентификатором тайла из установленного пакета, включая варианты ориентации, необходимые на контрольной улице. При отсутствии пакета подсказать, что установить, и дать собрать карту с ванильным вариантом.
2. Переиспользовать интеграцию Erika’s Tiles в [`knoxbuild/catalog.py`](../../knoxbuild/catalog.py), [`tools/make_catalog.py`](../../tools/make_catalog.py) и [`tools/make_map_mod.py`](../../tools/make_map_mod.py). Фиксировать фактическую ссылку на ресурс при выходе соответствующего этапа. На упаковке сверять используемые тайлы с данными скомпилированных ячеек, сохраняя поддержку прежних проектов с Erika.
3. Для каждой зависимости хранить точные `Mod ID` и `Workshop ID`. Идентификаторы сверять с установленным пакетом для целевой версии игры. Формировать `require=` в `mod.info` и серверные списки `Mods` и `WorkshopItems`, убирая дубликаты. Упаковщик выдаёт перечень для «Необходимых продуктов» опубликованной карты. Страница Workshop обновляется владельцем карты при публикации.
4. При использовании стороннего тайла в готовой карте упаковка должна обнаруживать отсутствующую запись о зависимости и указывать проблемный ресурс. Картограф должен видеть разницу между отсутствием желаемого пакета до сборки, когда доступна штатная замена, и отсутствием обязательного пакета после компиляции.

## 06Б. Другие виды ресурсов

- Для автомобилей задать роль, район, эпоху и относительный вес модели. Источники машин для обычных парковок, дорожных историй и сгоревших вариантов проверяются отдельно. P.A.R.C и отдельные модели остаются кандидатами до проверки состава и совместимости.
- Для предметов, одежды, мебели и вывесок задать назначение и место применения. Отличать тайл, встроенный в ячейку, от предмета или модели, на которые ссылается игровой код. Post-Soviet Bundle и другие наборы подключать по одному, чтобы видеть влияние на карту и её зависимости.
- Библиотеки зданий использовать при создании карты. Для выбранного здания фиксировать авторство и наборы, предоставляющие реально использованные тайлы. Ссылаться на пакеты через Workshop и учитывать условия использования. При необходимости подготовить собственные знаки, материалы или входные группы.

## Приёмка

- Первая пара сборок отличается выбранной разметкой. У варианта со штатными ресурсами новый пакет отсутствует в списке зависимостей. У варианта со сторонними тайлами точные ID согласованы в файле мода и инструкции сервера. Старый сценарий с Erika проходит прежний путь установки.
- Проверены повторная сборка, отказ при отсутствующем обязательном пакете и чтение всех используемых ресурсов на целевой версии игры. Публикация относится к отдельной проверке, совместимость набора фиксируется для конкретной версии B42 и режима игры.
